# Gaming Automation Workflows

Use this class-level skill for operating games or game servers from Hermes.

## Modded Minecraft servers

Absorbs `minecraft-modpack-server`. Handle CurseForge/Modrinth server packs, Java version selection, Forge/NeoForge install scripts, `server.properties`, EULA, JVM tuning, firewall, backups, and readiness checks. Ask for server preferences before generating config.

## Headless Pokemon play

Absorbs `pokemon-player`. Use a user-provided ROM only, run the emulator/server, expose a watch dashboard when appropriate, combine RAM state with screenshots, move in short action bursts, save before risky encounters, and record durable progress with clear prefixes.

## Safety defaults

Do not download copyrighted ROMs or game assets. Prefer tracked background processes, health checks, periodic saves/backups, and clear stop/resume instructions.
